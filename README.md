# kabirv.me

Personal portfolio of **Kabir Vashisht**, a CS + AI student and open-source contributor.

Live at **[kabirv.me](https://kabirv.me)**

## What's inside

- `index.html` — the whole site: one self-contained page, with no build step and no dependencies
- `CNAME` — tells GitHub Pages to serve the site on `kabirv.me`
- `.nojekyll` — tells GitHub Pages to serve the files as they are
- `banner.jpg` (optional) — add this file and it replaces the drawn night-sky banner

## Edit it

Open `index.html`, change what you want, then:

```bash
git add .
git commit -m "update portfolio"
git push
```

GitHub Pages redeploys in about a minute.
